Devflow 模型配置

独立配置页面支持按场景分配模型、调整推理强度、保存项目专属应用方式。Orca 继续作为主要执行承载层。

打开模型配置页面

如果页面无法连接，在本仓库运行：

npm run models:page

为其他项目打开配置：

node skills/axns-devflow-ext-autopilot/scripts/model-page.cjs --project-root D:/Coding/你的项目
