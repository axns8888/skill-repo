# Vue 3 前端开发约束

> 项目规范候选模板：使用前按当前项目事实裁剪，在项目基线中记录采用的规则和待定项。示例架构、界面布局、事务及迁移模式均需由项目确定。

## 先核对真实基线

读目标页面、同类页面、路由、领域 API 类型、公共组件和样式所有者。沿用目标项目组件库和设计系统，不把来源项目的 `Koi*`、`tk-*` 或特定页面骨架强制安装到其他项目。

新代码按目标项目约定使用 Vue 3 Composition API、`<script setup lang="ts">` 和明确领域类型。已有页面只在当前任务范围内调整，不为统一模板顺带重写。

## 分工与状态

| 层 | 职责 |
| --- | --- |
| 页面 | 组合查询、列表、表单、状态与用户动作 |
| 领域组件/composable | 可复用领域行为；明确输入、输出、卸载清理 |
| 公共组件 | 跨页面一致的表格、查询、详情、反馈及浮层 |
| 领域 API 与 DTO | 请求/响应类型和实际端点，复用统一请求层 |
| Pinia 或现有共享状态 | 跨页面字典、缓存、布局级面板；局部草稿无需新 Store |

异步操作维护加载/提交状态，在 `finally` 复位；沿用统一写入遮罩或禁用机制，不重复叠加。错误可见且允许恢复，保存失败保留输入，不能先显示成功再忽略失败。

对快速筛选/切换处理旧响应覆盖新结果的问题，采用既有取消或请求身份机制；卸载清理计时器、事件和订阅。仅在涉及这些路径时补验证，不为静态文案新增复杂状态框架。

## API 与值语义

- 页面只调类型化领域 API；服务地址、鉴权、响应与错误映射由统一请求层管理。
- 本地草稿、请求 DTO 和服务端实体有边界；保存后回读/刷新，再由真实返回更新页面。
- ID 使用契约规定的稳定类型，不因展示需要转成不安全数值；选择、展开、编辑与批量操作使用稳定 `row-key`，禁止用数组下标当身份。
- `0`、`false`、空字符串、`null`、缺省分别处理。开关若接口为 `0/1`，显式映射并保持写入类型，不能直接改成布尔。
- 业务选项、标签和状态使用项目唯一字典源；生成类型从其事实源再生，不手工复制允许值集合。
- 时间存储、时区、API 与显示格式分别确认；不能因格式改动改变时区或排序语义。
- 移除可见列或字段时同步清理筛选项、请求参数、重置、排序及导出中对应失效部分。
- 批量写遵守 [服务端批量契约](api-contracts.md)，不得通过请求层并发/重试机制把它变成多次单项业务写。

## 列表与表格

优先复用真实公共表格与卡片。列表具备明确加载、空态、错误态和有效数据状态，空态不用伪造首行或页面私有偏移修补。

当项目采用桌面主列表占满剩余高度的布局时：

1. 从页面、页签、面板到卡片传递可用高度，Flex 子项允许收缩；不靠固定视口高度凑效果。
2. 数据超出只在表体滚动；工具栏、查询、表头和同卡片底部分页保持可见。分页通过普通布局定位，不固定到窗口。
3. 页签或主从结构中的各表保留独立高度、选择及分页；嵌入抽屉的短表不能继承主列表大最小高度。
4. 验证空态、横向滚动、查询展开、页签切换、缩放和窄屏，且不改变分页/勾选/编辑/请求语义。

这套布局是来源项目的成熟模式；目标产品若采用整页滚动，遵守现行设计，不机械替换。

分页维护真实 `rows/total/page/page_size` 或项目对应字段。后端无分页能力时不伪造总数和“分页成功”。备注、比例、双时间、标签等有公共组件时复用，不复制第二套编辑状态机。

## 表单、抽屉和浮层

- 新增、编辑、详情使用既有公共外壳和模式，遵守其事件、插槽与关闭约定；结果只读与编辑态区分。
- 检查所有本次新增/修改浮层，包括确认、测试结果和共享业务组件；不能仅测内部表单而替换掉真实外壳。
- 必填、缺省、禁用、只读、错误定位及保存失败恢复语义明确。返回原生路径的对话框须在 Tauri 环境验证，网页模拟只证明网页行为。
- 验证打开、取消、提交失败、成功关闭、重新打开及已有的收起恢复；关闭后不残留脏状态和订阅。
- 字段用业务标签与可操作说明；不把内部 JSON、槽位、协议键名变成普通用户唯一的录入方式。
- 延续键盘焦点、标签关联、可读错误和既有可访问性；不用纯颜色表示用户必须识别的状态。

## 样式所有权

单页样式留在组件 scoped 且限定根节点；跨页相同语义进已有公共样式；主题/基础变量只在相应设计范围修改。公共样式改动先检索调用点并验证受影响页面。

不为单页问题修改全局组件主题，不复制已有空态/工具栏/卡片样式，不凭同名 class 就强行抽象；视觉语义、状态与范围一致才合并。避免无作用域深层选择器、随意 z-index、绝对定位和 `!important` 掩盖结构问题。

## 验证边界

按任务运行实际存在的领域测试、类型检查和受改范围 lint/样式检查；不自动全仓格式化或生产构建。

交互改动至少证明真实挂载事件 → API参数/本地状态 → 成功/失败显示；持久化改动补真实后端临时库回读。布局检查使用真实公共外壳和表格，断言表体实际可滚、外层几何和分页位置，不只查 CSS 类。

视口依据目标产品选取；桌面示例为 `1024×600`、`1366×768`、`1920×1080`，分栏补窄屏。截图按当前目标项目和会话授权执行，不继承来源项目的截图许可；截图不能替代交互与数据断言。

临时 Vite 验证必须使用任务独立端口和 `cacheDir`，避免复用运行中开发服务的预构建缓存；独立端口或 `configFile: false` 本身不代表缓存隔离。结束只停止本任务启动的服务。
