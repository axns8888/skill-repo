# Python + Vue 3 + Tauri 项目规范模板

这里保存可选的项目级模板，不包含独立技能入口。通用开发流程统一由 [axns-devflow](../../skills/axns-devflow/README.md) 提供。项目没有采用此技术栈时，无需复制本模板。

## 使用

1. 使用 axns-devflow 初始化目标项目的完整 _doc、_plan 目录骨架。
2. 根据项目实际需要，将本目录的 _plan/guides/ 中相关文件合并到目标项目的同名目录。它们是待裁剪的候选规则；只有项目确定采用的内容才成为约定。
3. 将 _plan/prompts/project.md 的技术事实、规范索引与采用决定合并到项目现有基线。新项目可用此模板填写基线；已有文件按段合并，保留已填写内容。
4. 核实版本、目录、真实命令、配置和接口约定，删去不适用章节。批量写策略、界面布局、迁移中转及打包工具都由项目确定。
5. 后续让 Agent 显式读取项目基线和任务相关规范。技能更新不会自动改写项目文档。

可直接交给 Agent：

```text
使用 $axns-devflow，为当前项目建立开发流程。
本项目已选择 Python + Vue 3 + Tauri，项目规范模板位于：〈本模板的实际路径〉。
先建立完整 _doc、_plan 最低目录骨架，再按仓库实际情况选取模板内容并填入项目基线和专题规范。
已有文件增量合并；未确定的选择标为待定，不将候选规则直接当作项目要求。
本次只生成流程和规范文档。产品目标：〈目标〉。
```

## 内容

- [项目基线](./_plan/prompts/project.md)：项目事实、真实命令与规范索引。
- [架构](./_plan/guides/architecture.md)：三端职责、配置来源、Sidecar 生命周期与目录。
- [前端](./_plan/guides/frontend.md)：组件、状态、值语义、布局与交互验证。
- [接口契约](./_plan/guides/api-contracts.md)：可选服务端批量操作、事务、审计与验证。
- [迁移与发布](./_plan/guides/release.md)：迁移、备份、版本和实际产物验证。

模板采用后由项目维护；仓库中的模板更新供项目按需比较合并。
