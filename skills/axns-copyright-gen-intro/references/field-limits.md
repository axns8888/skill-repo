# 软著登记信息 — 字段与字数

字数按 **Unicode 码位**计：`[...text].length`（Node）或等价实现。  
中英文、数字、标点均计 1；**不要**按「仅汉字」另算，除非用户明确要求。

## 默认限制表

| # | 字段名（登记表常见写法） | 限制 | 备注 |
| --- | --- | --- | --- |
| 1 | 开发的硬件环境 | ≤50 | 可写具体机型或「通用 PC + 配置」 |
| 2 | 运行的硬件环境 | ≤50 | Web：PC/服务器；H5：移动端存储/内存 |
| 3 | 开发该软件的操作系统 | ≤50 | 如 `WINDOWS 11` |
| 4 | 软件开发环境 / 开发工具 | ≤50 | IDE + 关键运行时/DB，须真实 |
| 5 | 该软件的运行平台 / 操作系统 | ≤50 | 如 `WINDOWS、Linux` |
| 6 | 软件运行支撑环境 / 支持软件 | ≤50 | 浏览器 / 运行时 / 中间件，常对齐案例写「基于Chrome内核的浏览器」 |
| 7 | 编程语言 | 拼接串 | 无空格、无顿号，如 `HTMLJavaScriptPythonSQL` |
| 8 | 源程序量 | 正整数 | 源码行数；注明统计路径 |
| 9 | 开发目的 | ≤50 | 价值一句话 |
| 10 | 面向行业 / 领域 | ≤50 | 行业 + 业务域 |
| 11 | 软件的主要功能 | 500～1300 | 叙事体；模块完整但不写未实现功能 |
| 12 | 软件技术特点 | ≤100 | 架构 + 关键技术 + 业务特色 |

## 校验脚本（可选）

```js
const n = [...text].length;
```

生成后每个字段必须实测；主要功能若 <500，补模块叙述；若 >1300，删冗余形容词与重复列举。

## 用户覆盖

用户截图或口述的限制优先于本表。常见变体：主要功能上限 2000、技术特点 200 等——按用户限制写，并在产出 MD 中改掉「≤xx」标注。
