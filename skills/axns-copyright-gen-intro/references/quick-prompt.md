# 一键提示词 — axns-copyright-gen-intro

复制到对话即可：

```text
按 axns-copyright-gen-intro 技能，为本仓库生成软著登记信息 Markdown。

项目名称：〈软件全称〉
端别：〈管理端 Web / 员工 H5 / 其他〉
源码统计路径：〈逗号分隔，如 apps/hr-web,apps/hr-server〉
后缀：.vue,.ts,.tsx,.js,.py,.scss,.css,.html,.sql,.json

字数限制（若与默认不同请改）：
- 环境类 / 开发目的 / 面向领域：各 ≤50
- 主要功能：500～1300
- 技术特点：≤100

输出路径：_doc/软著申请/〈项目名称〉-软著登记信息.md
要求：每字段独立代码块便于复制；标注字数；功能以仓库已实现为准。
```

## 带案例对齐

```text
按 axns-copyright-gen-intro，参照下列已提交案例的格式为本仓库补齐登记信息。
环境类短字段可对齐案例写法；开发工具与业务文案必须按本仓库改写。
项目名称：〈全称〉
端别：〈…〉
源码路径：〈…〉

—— 案例开始 ——
〈粘贴：开发的硬件环境 … 软件技术特点〉
—— 案例结束 ——
```

## 仅更新某一端

```text
按 axns-copyright-gen-intro 更新「〈项目名称〉」软著登记信息，
与另一端文件保持同级格式，勿混写功能。
```
