# Python + Vue 3 + Tauri 开发指南：使用说明

这份 skill 用于新建或接续 Python 后端、Vue 3 前端、Tauri 桌面项目，帮助 Agent 完成规划、开发、联调、复核和交付。使用示例都保存在 Markdown 中，换项目时按需修改需求即可。

## 新项目快速建立流程

新项目至少建立规定的完整 `_doc`、`_plan` 目录骨架，每个子目录有用途 README；目录定义及维护边界见 [最低结构与初始化](references/project-layout.md)。

在 Agent 中打开目标项目后可直接使用：

```text
使用 $python-vue3-tauri-guide，在当前项目初始化开发流程。
按技能规定创建完整 _doc、_plan 最低目录骨架及 README、flow.md，生成项目基线、阶段指南、任务模板和可复制提示词。保留已有文件与现行规范，按真实情况填写已知内容，未知项标记待核实。
本次产品目标：〈目标〉。本次只建立流程文档，业务开发将在后续任务中进行。
```

也可用本技能自带脚本一次建立；需要 Node.js，无第三方依赖。在任意目录执行，替换技能目录、项目路径及名称：

```powershell
node "<技能目录>/scripts/init-workflow.cjs" --project-root "<项目路径>" --project-name "<项目名称>"
```

加 `--dry-run` 可预览；重复执行只补缺失文件，已有文件逐字保留。初始化后先核实 `_plan/prompts/project.md`，再从 `_plan/prompts/stages.md` 选择本次阶段，真实任务放进 `_plan/process/`。没有 Node.js 时 Agent 可按模板手工生成相同结构。

## 最简单的用法

先在 Agent 中打开**要开发的项目**，并让 Agent 能够读取本 skill。技能已被当前工具识别时，复制下面这段，只替换需求：

```text
使用 $python-vue3-tauri-guide，阅读当前项目规范和相关源码，为以下需求制定实施计划，并完成已授权的开发与验证。
需求：〈填写本次需求和预期效果〉
```

例如，在已有项目中添加真正的批量操作：

```text
使用 $python-vue3-tauri-guide，为当前项目增加任务批量停用功能，完成相关后端、前端和验证。
用户勾选多条任务后一次提交给服务端；服务端校验并执行批量操作，前端展示每项结果并刷新真实状态。批量接口缺失时实现后端接口。
```

Agent 会先读取目标项目已有规范、目录与配置。你不需要先手工填写全部模板，也不需要每次粘贴完整开发规范。已有项目沿用实际技术方案；新项目再确定缺失的选型。

## 本机尚未安装或工具未识别名称

可以直接把 `SKILL.md` 的路径交给能够读取本机文件的 Agent。以下示例可在当前机器使用，项目路径替换成实际目标项目：

```text
请读取 D:/Coding/Axns8888/skill-repo/skills/python-vue3-tauri-guide/SKILL.md，并按其中指引读取本次任务需要的相对路径资料。
目标项目：〈目标项目的绝对路径〉。在这个项目中工作，先读取其规范和相关源码。
需求：〈填写本次需求和预期效果〉。
为需求制定实施计划，并完成已授权的开发与验证。
```

技能目录是规则来源，目标项目是本次工作的对象。二者可以位于不同位置。路径调用适合工具尚未发现技能的情况；仅输入技能名称而工具无法读取文件时，不代表技能已加载。

## 下次使用、换项目和交给其他用户

1. **下次继续同一项目**：打开该项目，使用下面的“继续已有任务”示例。先前会话内容不作为唯一依据，任务状态应能从项目记录和代码中恢复。
2. **换一个项目**：打开新目标项目，复用最简提示词并改写需求。若使用路径调用，同时替换目标项目路径。
3. **交给其他用户**：分享整个 `python-vue3-tauri-guide/` 目录，保留 `SKILL.md`、`agents/`、`references/`、`assets/` 和本说明。对方将目录放入其 Agent 支持的技能位置，或使用下面的直接路径示例。

接收者无需拥有原始 TK-Worker 项目或它的 `_doc`、`_plan`。本 skill 已包含独立资料；目标项目已有目录与规则优先，不要求复制来源项目结构。

给其他用户的通用路径示例：

```text
请读取〈本机技能目录的绝对路径〉/python-vue3-tauri-guide/SKILL.md，并按其中指引读取本次任务需要的相对路径资料。
目标项目：〈目标项目的绝对路径〉。
需求：〈填写本次需求和预期效果〉。
遵循目标项目已有规范，为需求制定实施计划，并完成已授权的开发与验证。
```

当前交付位于本地技能仓库；分享目录即可使用。通过远程仓库分发前，需要先将新增 skill 发布到对应仓库；本次文档整理没有执行提交、推送或远程安装。

## 常用阶段示例

每段都是可独立复制的完整指令。只选当前需要的阶段；不必每次走完所有阶段。

### 新项目启动

```text
使用 $python-vue3-tauri-guide，在当前目录启动 Python + Vue 3 + Tauri 项目。
产品目标：〈用户、核心功能和预期效果〉。
已确定的技术选型与运行平台：〈填写已知信息；未知项可留待讨论〉。
先检查目录和本机环境，建立技能规定的完整 _doc、_plan 最低流程骨架，填写已知项目基线。确定必要的架构与可运行入口，再完成已授权的业务初始化与验证。影响产品边界的未知项提出具体决策，普通实现选择按项目事实处理。
```

### 只做方案

```text
使用 $python-vue3-tauri-guide，为当前项目的以下需求制定实施方案，本次只交付方案文档。
需求：〈目标、成功标准和范围〉。
阅读项目规范和相关源码，列出影响模块、跨端接口、实施顺序与验证方式，明确待决策项。
```

### 继续已有任务

```text
使用 $python-vue3-tauri-guide，接续当前项目的任务〈任务名称、任务号或计划路径〉。
读取任务记录、现行计划、工作区改动和已有验证证据，恢复目标、授权与剩余事项，继续完成已授权范围，并更新实际结果。
本次补充：〈新约束；没有则删除本行〉。
```

### 自动复核

```text
使用 $python-vue3-tauri-guide，对当前项目的〈任务名称、计划路径或变更范围〉执行自动复核。
对照需求、实现和真实验证证据，按需核查前端到Python及Tauri的调用链、批量写入、数据库与异常路径。
报告缺陷、严重程度、证据和是否具备人工验收条件。本次只复核，修复另行安排。
```

### 准备人工验收

```text
使用 $python-vue3-tauri-guide，为当前项目的〈任务名称或计划路径〉生成可执行的人工验收清单。
依据实际实现和验证结果，列出环境、数据、操作步骤、预期结果与待验证项，明确需要用户确认的内容，保留真实的阶段状态。
```
