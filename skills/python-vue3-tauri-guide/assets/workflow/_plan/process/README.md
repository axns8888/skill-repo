# 进行中的任务

新任务按需建立 tasks/<任务标识>/ 或单个任务文档，内容参考 [任务记录模板](../guides/task-records.md)。接续任务先恢复目标、已有授权、唯一现行计划、工作区变更、有效证据和未关闭项。

| 任务 | 目标与当前阶段 | 现行计划、证据与结论入口 | 下一步 |
| --- | --- | --- | --- |

首次执行时填写真实任务，不预填虚构记录。已实现、自动验证、交验资格、用户确认和结案分别记录；待验收清单随任务维护，不自动标记通过。

完成后更新 [任务台账](../ledger/README.md)，延期范围转入 [future](../future/README.md)。过程记录按项目保留规则处理，结案不默认删除任务目录。
