# 源码文档版式与版权局要求

默认值由本次任务的 `*-ruanzhu-code-config.md` 控制，详见 [docx-style.md](./docx-style.md)。

## 版权局（程序鉴别材料）对齐

| 要求 | 本技能默认 |
| --- | --- |
| 每页不少于 **50** 行（有效代码） | `linesPerPage: 50`；按有效行分页；`stripComments` 去纯注释 |
| 有效行数 **> 50** 时保留空行 | 默认 `stripBlank: false`；有效行 > 50 时忽略 `stripBlank: true` |
| 一般 **前、后各连续 30 页**，共 **60** 页 | `pages: 60`，`mode: head-tail`（前 1500 + 后 1500 行，中间不插标记） |
| 全文不足 60 页（有效行 &lt; 3000） | **提交全部**，页数按实计算，不用空行/空注释凑页 |

## 页面

- 纸张：A4  
- 页边距：约 0.5 英寸  
- 正文字体：默认 **Times New Roman 12pt**（`code.body`）  
- 目标总行数：60×50 = **3000** 行（足量时）  

## 页眉 / 页脚

- 页眉居中：`{projectName}  {version}`  
- 页脚居中：默认 `{page}`  
- 宋体 12pt、黑色、无粗斜体  

## 正文内容

- 文件分隔：`// ===== FILE: relative/path =====`（保留，便于核对）  
- 默认去除：纯注释 / 块注释；**有效行 > 50 时保留空行**  

- 单行超过 120 字符截断加 `...`  
- 排除 `node_modules`、`__pycache__`、`__init__.py` 等  

## 模式

- **head-tail（默认）**：按路径拼成连续程序后，取前一半页 + 后一半页  
- **consecutive**：按 `paths[].weight` 配额从头连续截取（非版权局默认，慎用）
