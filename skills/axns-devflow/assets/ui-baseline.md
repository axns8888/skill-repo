# 〈项目名称〉UI 与交互规范

有界面时，在首个页面实现前具体化本文件；无界面项目在基线注明不适用。以现有设计、组件库和用户要求为准；没有设计稿时执行者根据目标用户建立统一方案并实现，不把空模板当作设计结果。

## 项目决定

- 目标用户、设备、界面语言、信息密度与视觉方向：〈结合产品填写〉
- UI 框架、组件库、图标、样式方案及现有事实源：〈版本/入口按项目核实〉
- 应用壳与导航、页面区域、路由及领域目录：〈准确路径和复用方式〉
- 公共组件清单、可参考的真实页面与领域组件入口：〈职责、路径及使用规则〉
- 视口/断点、滚动责任、长内容和窄屏策略：〈具体尺寸及预期〉

## 设计令牌与样式归属

| 维度 | 本项目决定/唯一入口 | 无既有方案时的起点 |
| --- | --- | --- |
| 颜色 | 〈品牌、文本、背景、边框、成功/警告/错误/禁用〉 | 一套语义色；状态同时提供文字或图标，不能只靠颜色 |
| 字体 | 〈字体、标题/正文/辅助字级、字重与行高〉 | 正文 14–16px、辅助 12–14px、标题 20–24px，按产品定档 |
| 间距 | 〈令牌及使用场景〉 | 4/8/12/16/24/32px；控件、区块和页面各使用固定档位 |
| 控件与形状 | 〈高度、圆角、边框、图标、阴影和层级〉 | 沿用组件库尺寸，一致的表单和按钮密度 |
| 布局 | 〈页边距、栅格/宽度、标题、工具栏、表格与分页〉 | 页面留白和区块间距统一，明确外层与内容区的滚动归属 |

上述数值是无设计时的候选起点，实施前选成项目实际令牌，不能在各页自由选择。令牌和公共样式维护在唯一入口；页面样式仅处理本页独有布局，不复制主题、按钮、抽屉、表格和空态样式，不用全局覆盖修补一个页面。

## 组件与目录责任

- 公共应用壳承载导航、页头和内容区；路由页负责该用例编排，页面独有组件放附近，领域组件放所属领域，跨领域能力才进入公共组件。
- 相同交互使用同一组件或库能力：查询区、工具栏、列表、分页、表单、抽屉/对话框、反馈和状态标签确定统一入口；已有封装先复用，不每页重新实现。
- 页面通过领域 API/状态入口取数和提交，不在模板或组件内散落请求地址、协议转换和业务字典。数据来源、筛选、排序、分页及选中状态的责任明确。

## 页面模式

| 页面/操作 | 应约定并实现的行为 |
| --- | --- |
| 列表 | 标题、查询/重置、主操作、列与操作区、排序/筛选/分页、选中批量行为；仅实现本期用例需要的项 |
| 新增/编辑 | 标签和必填/格式提示、初值、字段错误、提交中与防重复、成功后回显、失败保留输入、取消/关闭策略 |
| 详情/设置 | 信息分组、长内容/时间/枚举展示、加载与缺失、修改保存和反馈；不把调试 JSON 当作面向普通用户的唯一交互 |
| 危险操作（适用时） | 清楚的对象与影响提示、项目既定确认方式、进行中、失败反馈与列表/详情同步 |
| 导航与多状态 | 当前页/页签可辨认，刷新及返回行为明确；未实现能力不显示为可操作成功入口 |

## 状态、可访问性与适配

- 按真实用例覆盖初始加载、正常数据、首次空数据、筛选无结果、请求失败/重试、处理中、成功和禁用；权限状态仅在产品已有权限模型时适用。不以演示占位数据遮盖空态或失败。
- 表单有可识别标签；键盘可达、焦点可见，弹层遵循组件库的焦点/关闭行为。错误紧邻相关输入，按钮文案说明实际动作。
- 长文本、数据量变化、表格两轴滚动、弹层高度、缩放和窄视口均按页面布局考虑；不能只有单一宽屏截图看起来可用。
- 页面用语面向目标用户，统一业务名称、操作动词和时间/数量格式，避免暴露内部类名、协议名或实现过程。

## 受影响页面验证

在任务计划中列页面/状态/视口/操作与预期。使用真实挂载的页面观察主布局、长内容和滚动，并验证查询、保存、错误及状态保持等受影响交互。截图可以支持视觉结论，不能替代数据和副作用断言；使用替代 API 时写明边界。记录已验证和未验证项，不因类型检查通过就宣称 UI 完成。
