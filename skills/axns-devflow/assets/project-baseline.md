# 〈项目名称〉开发基线

仅保留当前项目需要的章节。已有等价规范时增量补充，不维护第二份同义基线。填写可核实事实；未知项给出核实动作。技术栈填写项目实际选择，本模板不预设语言、框架或应用形态。

## 流程目录与入口

新项目先建立完整最低目录骨架，见 [目录与初始化](../references/project-layout.md)。业务源码和工具目录按实际技术栈确定。

- 项目资料：`_doc/README.md`；子目录 `demos/`、`scripts/`、`使用说明文档/`、`第三方插件文档/`。
- 开发流程：`_plan/README.md` 与 `_plan/flow.md`；子目录 `future/`、`guides/`、`ledger/`、`process/`、`prompts/`。
- 当前基线与可复制指令：`_plan/prompts/project.md`、`_plan/prompts/stages.md`；通用阶段规则与模板：`_plan/guides/`。
- 任务计划与证据：`_plan/process/`；台账与验收归档索引：`_plan/ledger/`；延期事项：`_plan/future/`。
- 已有等价载体及映射：〈已核实的唯一入口；新项目使用上述位置〉。最低骨架保留，具体任务记录按规模创建。

## 编程器与 IDE 协作

接入分工与流程见 [工具协作](../references/tool-integration.md)，以下仅记录本项目选择。

- 主要执行平台及已核实版本：〈DSH / Orca；按实际填写〉；同一项目的主要自动化唤醒入口：〈规则及执行位置〉。
- 原生清单沿用项目 task-id 并组织当前阶段步骤；范围、成功标准和证据入口仍以原任务计划为准，不重复维护清单历史。
- PyCharm 打开同一任务目录，解释器、终端及运行配置按本项目命令表设置；人工接手运行阶段前协调原执行权。
- 跨平台先结束原派发再切换唤醒入口；启用 autopilot 时以 owner / dispatch_id 和 request.cwd 为准。平台投递或清单完成不等于任务验收。

## 任务窗口与可选扩展

- 默认单任务；正式登记用 `_plan/.active_plan`，任务位于 `_plan/process/<task-id>/`。
- 可复制的窗口协议从 [P0 开窗](../prompts/window/P0-open.md) 开始，P1–P4 共用，P5 仅 worktree 扩展启用时使用。
- 是否启用 worktree 只由项目 AGENTS.md 的 `extensions` 决定，本基线不维护第二份开关。未声明时不创建 worktree 或共享登记。
- 启用时需同时可读取 axns-devflow-ext-worktree，AGENTS.md 明确本地 `integration_branch` 及可选 `lock_timeout_minutes`（默认 120）；按扩展说明配置忽略项并处理旧单指针。
- 主检出目录及其共享 active/registry 位置、任务范围与共享文件、验收和本地自动收尾边界：〈从项目事实核实；已授权任务默认提交、合入、归档并删除本任务 worktree/分支，用户明确保留或等待要求优先；不开扩展则不适用〉。
