# 使用端里程碑验收与反馈

此文件用于记录技能或流程在真实目标项目中的使用结果。由目标项目维护；复制到对应任务的 `_plan/process/<task-id>/` 后填写。模板不代表任何里程碑已经执行或通过。项目特有的使用方式、工具配合及约束仍由 `_plan/project/` 维护。

本记录只反馈使用端观察，不替代实施自检、独立复核、技术验收、合入、finish 或任务结案。未实际执行的项目标记为“未执行”，不得推定通过。涉及隐私或敏感信息时只记录脱敏后的证据位置和复现信息。

- 原任务及权威记录：〈task-id、计划路径〉
- 目标项目与实际使用流程：〈项目、使用者角色、采用的技能/版本〉
- 受测代码或配置版本：〈commit、发布号或可追溯标识〉
- 环境与前置条件：〈操作系统、工具/平台版本、权限、数据、必要配置〉
- 执行者与日期：〈身份或角色、日期/时区〉
- 本轮目标与不覆盖范围：〈本次实际要验证什么〉
