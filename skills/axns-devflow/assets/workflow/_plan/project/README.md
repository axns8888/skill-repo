# {{project_name}} 项目约定

本目录由目标项目自行维护，记录项目如何使用技能、工具或平台如何配合，以及项目额外要求。它补充 `_plan/prompts/project.md`，不复制项目总计划、模型/执行配置或 `AGENTS.md`。

| 文件 | 职责 |
| --- | --- |
| [skill-usage.md](skill-usage.md) | 项目采用的技能、适用范围、调用入口和项目侧约束 |
| [coordination.md](coordination.md) | 项目实际使用的工具/平台分工、任务权威来源与交接规则 |

初始模板中的未填写项均为待核实，不代表相关工具或技能已安装、可用或启用。以项目明确配置和负责人决定为准；不要从提及、安装或模板内容推断启用。项目可按实际需要增加文件，并在此登记唯一事实源。

由技能按项目事实生成的内容应标明生成状态（草稿/已审阅）、事实依据、审阅人或责任角色及待确认项。审阅前仅作候选内容；事实变化时由项目维护者更新。已有等价规范应链接映射，不复制出互相冲突的版本。
