# 阶段指南与模板

这里维护跨任务通用规则。项目技术选型和领域契约写入 [项目基线](../prompts/project.md)，具体任务结果写入 [process](../process/README.md)。

| 文件 | 用途 |
| --- | --- |
| [目录与初始化](project-layout.md) | 最低目录结构、快速创建及接续规则 |
| [人工验收配置](../../../../references/acceptance.md) | 独立开关、任务阻塞范围及人工状态 |
| [工作流](workflow.md) | 阶段职责、规划、交接、验收和结案 |
| [质量门禁](quality-gates.md) | 成功标准、证据、失败归因和交验资格 |
| [任务记录模板](task-records.md) | 按规模抽取事实、计划、证据、复核和确认章节 |

只复制本次任务需要的模板章节；小任务可合并成一份记录。完整目录骨架保留，不为每个任务预造空计划或空验收文件。

DSH / Orca 原生自动化、任务清单与 PyCharm 协作见 [工具协作](tool-integration.md)。
