# P5 阶段 4：升级协调（仅 worktree 扩展启用）

执行 axns-devflow 阶段 4。当前 task-id：{{task-id}}。扩展未启用时不使用。

先回报触发事实及证据，任一满足即暂停：

- 同一任务 rebase 后两次出现相同冲突。
- 两个任务方案互不兼容。
- 同一 CI 检查连续两次失败，且原因涉及共享文件。
- shared_claims 等待超过 AGENTS.md 的 `lock_timeout_minutes`，默认 120 分钟。

调用扩展 escalate，追加 `task.escalated` 事件，暂停执行并保留已有持权；不自动转给其他窗口。记录涉及任务、尝试方案、证据、待裁决事项及可选方案。不得自行扩大 scope、弱化规则、偷取持权或自动重试有副作用的操作。

用户裁决后记录决定，按扩展协议重新仲裁再恢复；变更范围先取得范围变更授权。

回报：触发条件、涉及任务、已尝试方案、待裁决事项、建议选项；不替用户作决定。
