# 软著申请素材说明模板（`软著申请-<端>.md`）

用于材料包内留档，便于下次修订或交给其他 Agent。

---

```markdown
# 软著申请素材说明 — 〈端别名〉

## 产出物

- **格式样板：** [`demo/〈样板文件名〉.docx`](./demo/)（若有）
- **正式操作手册：** [`〈项目名称〉-操作手册-v1.md`](./〈项目名称〉-操作手册-v1.md)
- **Word 交付：** [`〈项目名称〉-操作手册-v3.docx`](./〈项目名称〉-操作手册-v3.docx)
- **截图目录：** [`Screenshot-〈端〉/`](./Screenshot-〈端〉/)
- **撰写规则：** [`rule/project_rule.md`](./rule/project_rule.md)
- **总览：** [`README.md`](./README.md)

## 申请信息

| 项 | 内容 |
| --- | --- |
| 项目名称 | **〈项目名称〉** |
| 申请端 | 〈管理端 Web / 移动端 H5 / …〉（代码路径：`apps/…`） |
| 手册范围 | 仅本端；不展开其他端 |

## 技术说明（写入「运行环境」）

- 服务端：〈栈〉
- 本端前端：〈栈〉

## 功能范围依据

- 需求/模块文档：〈链接〉
- **以仓库当前路由/菜单/页面实现为准**（见手册第 3～5 章）

## 截图最低集

见 [`Screenshot-〈端〉/README.md`](./Screenshot-〈端〉/README.md)。

## 后续修订清单

- [ ] 实拍/重拍截图并确认非登录误截
- [ ] 项目名称全文统一
- [ ] 图号连续；删除未用占位
- [ ] 按代理机构要求调封面字体与页眉页脚
```

```text
必须含【图n　标题】与字段级操作步骤；汉字≥8000；
禁止描述未实现功能；演示账号与 URL 使用：…
输出路径：_doc/软著申请/〈项目名称〉-操作手册-v1.md
```
