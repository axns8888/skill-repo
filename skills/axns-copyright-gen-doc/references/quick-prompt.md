# 一键提示词（复制到任意项目对话）

把下方 `〈〉` 换成你的项目信息即可。Agent 应加载 **axns-copyright-gen-doc** 技能执行全流程。

---

## 标准版（推荐）

```text
请按技能 axns-copyright-gen-doc，为本仓库生成中国软著「用户操作说明书」。

【项目信息】
- 项目名称：〈例如：某某管理系统〉
- 端别：〈仅管理端 Web / 仅移动端 H5 / Web 与 H5 各出一套独立软著〉
- 若双端：第二套项目名称：〈例如：某某移动端〉（必须与第一套不同）

【环境】
- 管理端 URL：〈http://127.0.0.1:xxxx〉 账号〈admin〉/〈密码〉
- 移动端 URL：〈http://127.0.0.1:yyyy〉 账号〈emp〉/〈密码〉
- 路由模式：〈history / hash〉（不确定则从代码推断）

【格式】
- 若存在 `_doc/软著申请/demo/*.docx`，章节结构与字段级步骤密度对齐该 demo
- 否则使用技能内默认大纲（封面/目录/引言/环境/登录/概述/详细步骤/FAQ/附录）
- 正文每端不少于 8000 汉字；详细步骤须字段级说明，并插入【图n　标题】

【产出】
1. `_doc/软著申请/` 材料包（README、rule、软著申请说明、Screenshot 清单）
2. `<项目名称>-操作手册-v1.md`（命名：项目名称-类型-版本）
3. 自动截图到 Screenshot-*（服务需已启动；用本机 Chrome/Edge）
4. 导出嵌图 Word：`<项目名称>-操作手册-v3.docx`
5. 汇报路径、汉字数、图数、文件大小与重跑命令

【约束】
- 只写仓库已实现功能，禁止虚构
- 一手册只写一端；项目名称全文统一
- 截图后抽检，避免整本都是登录页
```

## 精简版

```text
按 axns-copyright-gen-doc：从本仓库已实现功能生成软著操作说明书（Markdown+自动截图+嵌图 Word）。
项目名称：〈全称〉；端：〈Web/H5/双端〉；演示：〈URL+账号〉；有 demo 则对标格式。
```
