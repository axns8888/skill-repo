# skill-repo 工具协作约定

状态：按本仓库现有文件核实，2026-11-22；平台账号/运行态未经本文件验证。

## 事实源与职责

| 事项 | 本仓库事实源 | 约定 |
| --- | --- | --- |
| 技能源码和版本 | `skills/` 下技能文件 | 对应 `SKILL.md` 是版本元数据来源；README 展示记录需同步 |
| 技能内容完整性 | `skills.lock.json`、`scripts/skills-local.cjs` | 改动后更新锁并校验；锁通过不等于测试或平台验收通过 |
| 命令及运行环境 | `package.json`、`.nvmrc`、`engines.node` | 使用仓库声明的 Node 环境；具体命令须实际执行后才记为验证证据 |
| 跨会话任务计划 | `.planning/.active_plan` 指向的计划目录 | 按当前任务选择器接续；不要将同一任务另复制到 `_plan/process/` |
| 通用流程骨架 | `_plan/` | 提供本仓库可维护的 devflow 约定入口；与现有 `.planning` 活动计划用途区分，不追溯复制旧任务 |
| 本机安装副本 | `docs/local-development.md` 所述目标及本地收据 | 仅在明确授权同步后操作；不作为仓库源码事实源 |

## 工具与执行边界

| 工具 | 本仓库职责 | 使用边界 |
| --- | --- | --- |
| Git | 记录源码、模板、测试和需求文档变更 | 开始前检查状态/diff；保留其他未提交改动，不擅自重置、覆盖或清理 |
| Node.js / npm | 脚本、定向测试和仓库验证 | Node 版本依据 `.nvmrc` 与 `package.json`；报告实际执行命令和结果 |
| skills-local 脚本 | 更新锁、校验及按授权同步技能 | `verify` 不代替测试；`sync` 会影响安装目标，须按任务授权执行 |
| Agent 会话/子代理 | 按不重叠文件范围并行审查或实现 | 主会话核实目标和工作区，负责跨模块整合、复核及最终验证 |

扩展状态：仓库根目录没有 `AGENTS.md` 的 autopilot/worktree 声明。相关源码、配置页或扩展说明存在不构成启用；本项目任务默认在当前工作区执行，不创建或登记 worktree，不启用自动派发。

任务计划以当前被选中的 `.planning/.active_plan` 为准。新项目级执行约定只记录稳定事实，不复制具体任务计划；如未来迁移计划载体，应一次性明确旧记录归档与新权威入口，不能同时维护两份活动计划。
