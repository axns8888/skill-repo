本目录由目标项目自行维护，记录项目如何使用技能、工具或平台如何配合，以及项目额外要求。它补充 `_plan/prompts/project.md`，不复制项目总计划、模型/执行配置或 `AGENTS.md`。

| 文件 | 职责 |
| --- | --- |
| [skill-usage.md](skill-usage.md) | 项目采用的技能、适用范围、调用入口和项目侧约束 |
| [coordination.md](coordination.md) | 项目实际使用的工具/平台分工、任务权威来源与交接规则 |

本仓库当前已核实技能来源、扩展状态及计划入口；具体事实见下列文件。后续改动按代码、配置和负责人决定更新，不从技能/工具被提及或安装推断项目已启用。项目可按实际需要增加文件，并在此登记唯一事实源。

由技能按项目事实生成的内容应标明生成状态（草稿/已审阅）、事实依据、审阅人或责任角色及待确认项。审阅前仅作候选内容；事实变化时由项目维护者更新。已有等价规范应链接映射，不复制出互相冲突的版本。当前内容按 2026-11-22 仓库检查维护。
